# FileShelf

Enter **/fileshelf** in the local Windows Code session that contained your file. The pane searches the conversation's retained history, including messages from before you installed the plugin. Choose a filename to read its original message, follow a download link or save an available version in your user profile's **FileShelf Recovery** folder.

**Shared** lists file links, presented files and supported assistant attachments. **Tool writes** lists the text of successful Write calls. A **Message only** entry still has its reference, but FileShelf has no file contents to save for it.

Requires a native local Claude Code engine 2.1.331+ and Node.js 22+ on PATH. The reader runs on demand and keeps no persistent transcript index. See the repository README for installation, tests and recovery limits.
